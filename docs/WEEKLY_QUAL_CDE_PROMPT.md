# 주간 정성 C/D/E 보완 AI 프롬프트

**용도:** A_CECS_SUMMARY만 채워진 `weekly_qual_report_YYYYMMDD_filled.md`에  
C(T2) / D(논지) / E(목표가) 빈칸을 채울 때 사용.  
**출력:** 완성 Markdown 전체 또는 C~E 섹션만. 헤더·필드명 변경 금지.

---

## 설계 원칙 (운용자용)

1. **범위 분리** — A(CECS)는 이미 있음. AI는 C/D/E(선택: B 심층)만 채운다.
2. **파서 계약 우선** — `##` / `###` / `- 필드:` 라벨을 한 글자도 바꾸지 않는다.
3. **발화·훼손은 보수적** — T2 `fired=true`, 논지 `damage=true`는 1차 출처로 “확정”된 경우만.
4. **영역 독립** — 한 섹션 실패가 다른 섹션을 막지 않으므로, 확인 불가면 그 칸만 `확인 불가`+검색 키워드.
5. **목표가 ≠ 매수 제안** — exit YAML용 상한/목표가. `target_portfolio.csv` 변경 제안 금지.
6. **사람 결재 전제** — AI는 제안만. 업로드 후 결재함에서 출처·내용 검토 후 영역별 승인.

---

## 복사용 프롬프트 (외부 AI에 붙여넣기)

아래를 통째로 복사한 뒤, `[첨부]`에 현재 filled MD를 붙이세요.

```text
당신은 한국 주식 정성 조사 보조입니다. 아래 첨부 Markdown은 주간 통합 정성 리포트입니다.
A_CECS_SUMMARY(30종)는 이미 작성되어 있습니다. 당신은 C_T2_EVENTS / D_THESIS / E_TARGET_VALUATION
빈칸만 채우세요. (가능하면 B_FINAL6_DEEP도 채우되, 필수 우선순위는 C→D→E.)

# 절대 규칙
1. 섹션 헤더(`## C_T2_EVENTS` 등)와 필드 라벨(`- fired:`, `- 근거:`, `- 출처:` 등)을 변경·삭제하지 마세요.
2. 종목 블록 헤더 `### EVENT [...]`, `### THESIS`, `### TARGET [티커] 이름` 형식을 유지하세요.
3. 추정 금지. 확인 불가면 근거에 `확인 불가; 검색 키워드: "..."`를 쓰고 출처에 `확인 불가`를 적으세요.
4. 출처는 줄마다 URL을 단독으로 적어도 됩니다. 예: `- https://...`
5. A_CECS_SUMMARY 본문은 수정하지 마세요. 참고만 하세요.
6. `target_portfolio.csv` 변경·편입/편출 제안은 금지입니다.
7. 출력은 첨부 파일 전체(빈칸만 채운 완성본)로 주세요. 설명 문단·서론 없이 Markdown만.

# as_of / 기준일
- 리포트 as_of를 따르세요. (첨부 상단 `as_of` 값)
- “오늘 시점”이 아니라 그 as_of 기준으로 확정 여부를 판정하세요.

# C_T2_EVENTS — 제도 이벤트 (3건)
각 EVENT마다 반드시:
- fired: true 또는 false 만
- 근거: 한 줄 이상 (_____ 금지)
- 출처: URL 또는 확인 불가

확정 인정 기준 (엄격):
1) commercial_code_enforcement_decrees
   - 질문: 상법 관련 시행령·시행규칙이 ‘확정’되었는가?
   - true 조건: 관보 게재. 입법예고·보도만이면 false.
2) msci_dm_index_inclusion_confirmed
   - 질문: 한국(또는 해당 시장) MSCI DM 지수 편입이 ‘확정’ 발표되었는가?
   - true 조건: MSCI 공식 편입 발표. 워치리스트·전망 보도는 false.
3) ifrs18_domestic_adoption_schedule_confirmed
   - 질문: IFRS18 국내 도입 일정이 ‘확정’되었는가?
   - true 조건: 금융위 또는 한국회계기준원 확정 고시. 검토·의견수렴만이면 false.

의심스러우면 fired: false. true는 1차 출처 URL이 있을 때만.

# D_THESIS — 논지 훼손
반드시:
- damage: true 또는 false
- 근거: _____ 금지
- 출처: URL 또는 확인 불가

판정 초점:
- 투자 논지(주주환원·지배구조 개선·밸류업 제도 환경)를 훼손하는 신규 사건/후퇴/유예가 as_of 기준으로 확정되었는가?
- 단순 주가 하락·개별 실적 부진만으로는 damage:true 금지.
- damage:true는 1차 출처가 있을 때만. 불확실하면 false + 근거에 관측 범위 명시.

# E_TARGET_VALUATION — 제안 6종 목표가
대상 티커(헤더 그대로):
- 036530 SNT홀딩스
- 006040 동원산업
- 005830 DB손해보험
- 271560 오리온
- 005440 현대지에프홀딩스
- 021240 코웨이

각 TARGET마다 반드시:
- **이 요청서 양식만 채운 완성본**을 낸다. `_reference`/조사메모/참고자료 파일로 대체 금지.
- pbr_max: **숫자만** 또는 `_____`. 예: `0.60`
  금지: `0.75배`, `0.7배 (2028년 목표)`, `_____ (참고: 0.54~0.66)`, `1.4배 (대신증권…)`
- target_price: **원 단위 숫자만** 또는 `_____`. 예: `42000`
  금지: `48,000원`, `200,000~250,000원`, `_____ (참고: 컨센서스…)`, `150000원 (한화…)`
- 둘 중 최소 1개는 숫자로 채울 것 (둘 다 _____면 업로드 실패)
- 증권사명·범위·주석은 `펀더멘털 사유`/`근거`에만 (값 줄에 `(참고:…)` 붙이지 말 것)
- 펀더멘털 사유: _____ 금지 (왜 그 상한/가격인지 펀더멘털 한두 문장)
- 근거: _____ 금지 (수치·공시·밸류에이션 논리)
- 출처: 최소 1개 http(s) URL (확인 불가만이면 업로드 실패)

작성 가이드:
- 이것은 익절/밸류에이션 상한 제안이지 매수 추천이 아님.
- A섹션에 이미 있는 환원·지배구조 사실을 재사용해도 됨. 숫자는 출처로 뒷받침.
- 기존 yaml 초안이 있어도 맹목 복사 금지. as_of 기준으로 재검토한 값을 적을 것.
- pbr_max는 배수 숫자(예: 1.20), target_price는 원 단위 정수(예: 48000). 단위 문자 붙이지 말 것.

# (선택) B_FINAL6_DEEP
시간 되면 6종 DEEP의 공시/자사주·배당/연기금/투자목적/리스크/출처도 채우세요.
필수 실패를 막으려면 C/D/E를 먼저 완성하세요.

# 자기점검 (출력 전)
- C: 3 EVENT 모두 근거 ≠ _____
- D: 논지 근거 ≠ _____
- E: 6 TARGET 모두 펀더멘털 사유·근거 ≠ _____, (pbr_max|target_price)≥1, 출처 URL≥1
- 헤더/필드명 불변
- A섹션 미수정

[첨부: weekly_qual_report_*_filled.md 전체]
```

## 사용 절차

1. 위 프롬프트 + 현재 filled MD를 웹검색 가능 AI에 넣기  
2. 받은 완성본을 `docs/weekly_qual_report_YYYYMMDD_filled.md`로 저장  
3. 결재함 → **2. 완성본 업로드**  
4. T2 / 논지 / 목표가 보고서 훑고 영역별 승인  
5. CECS는 이미 승인했다면 다시 안 해도 됨 (영역 독립)

## 실패 시 빠른 체크

| 메시지 | 조치 |
|--------|------|
| `근거 필요` / `논지 근거 필요` | `_____` 남아 있음 → 문장으로 교체 |
| `펀더멘털 사유 필요` | `- 펀더멘털 사유:` 채우기 |
| `pbr_max 또는 target_price 필요` | 둘 중 하나 **순수 숫자**. `48,000원`/`0.75배`/`범위~`/`(증권사…)`면 실패 → `48000` / `0.75` |
| `출처 필요` | http(s) URL 최소 1개 |
| `fired는 true/false 필요` | `true`/`false`만 (예/아니오 금지) |
